### 📖 About this project / О проекте

This repository contains a full **Data Warehouse Project** built with SQL Server — covering Medallion Architecture (Bronze → Silver → Gold), ELT processing, data modeling (Star Schema), data integration from CRM & ERP systems, and analytics-ready reporting layers.

Этот репозиторий содержит полный **проект хранилища данных** на SQL Server — включая Medallion Architecture (Bronze → Silver → Gold), ELT-обработку, моделирование данных (Star Schema), интеграцию данных из CRM и ERP систем, а также слой, готовый для аналитики и отчётности.
